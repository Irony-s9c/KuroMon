# KuroMon

Windows 11 向けのハードウェアモニターです。CPU / GPU / RAM の使用率と温度をリアルタイムに表示し、通知領域に常駐して温度を数字で確認できます。ゲーム中・配信中でも見やすいオーバーレイと、ゲーム向けのメモリ解放機能を備えています。

## 主な機能

- **ダッシュボード** — CPU / GPU / RAM ごとに、使用率と温度を大きな数字で並べて表示します。状態（正常 / 注意 / 危険）は色と文字の両方で示し、直近 60 秒の推移をグラフで確認できます。
- **オーバーレイ** — 使用率と温度を常に最前面の小さなバーに表示します。ゲームのフォーカスを奪わず、ドラッグで移動、クリック透過にも対応します（ウィンドウ表示 / ボーダーレス表示のゲームで利用できます）。
- **メモリ最適化** — バックグラウンドのプロセスの作業セットとスタンバイリストを解放し、ゲームが使える空きメモリを増やします。手動実行に加え、全画面のゲームを検出してメモリ使用率がしきい値を超えたときに自動で実行するモードがあります。ゲーム本体・配信ソフト・Windows のシステム プロセスは対象外です。
- **通知領域への常駐** — 選択した値（CPU 温度など）をアイコンに数字で表示し、クリックで各値をまとめたミニパネルを開けます。
- **ハードウェア情報** — CPU / GPU / ディスプレイ / メモリ / マザーボードの詳細を表示し、テキストとしてコピーできます。
- **高温警告** — CPU / GPU が高温の状態が続くと通知します。
- **自動起動・自動アップデート** — Windows へのサインイン時に通知領域で起動し、新しいバージョンを自動で確認します。
- **ダーク / ライトテーマ** — 半透明のガラス調デザイン（Mica / アクリル）。Windows の「透明効果」「アニメーション効果」の設定に従います。

## 動作環境

- Windows 11（64 ビット）。ガラス調の背景は Windows 11 22H2 以降で表示されます。
- **管理者権限が必要です。** ハードウェアのセンサーを読み取るため、起動時に UAC の確認が表示されます（自動起動時は確認なしで起動します）。
- **CPU 温度の表示には PawnIO ドライバーが必要です。** インストーラーは PawnIO が入っていない場合に自動でインストールします。未導入の場合は画面の案内からインストールできます。PawnIO が無い環境では CPU 温度が「N/A」になります。
- RAM の温度は、温度センサーを搭載した DDR4 / DDR5 メモリでのみ表示されます。
