# KuroMon 更新履歴

バージョン表記は [セマンティック バージョニング](https://semver.org/lang/ja/) に従います。

## v1.0.0 - 2026-10-20

Musubi（https://musubi-bot.xyz）での配布を始めた最初の版です。

- CPU / GPU / RAM の使用率と温度を表示するダッシュボード（状態表示、直近 60 秒のグラフ）。
- ゲーム中・配信中に使えるオーバーレイ（最前面表示、フォーカスを奪わない、クリック透過）。
- ゲーム向けのメモリ最適化（手動実行、全画面ゲームの検出による自動実行、除外プロセスの指定）。
- 通知領域への常駐（数値アイコン、ツールチップ、ミニパネル、右クリックメニュー）。
- CPU / GPU / ディスプレイ / メモリ / マザーボードのハードウェア情報とコピー。
- 高温警告、Windows 起動時の自動起動。
- 起動時と 6 時間ごとに Musubi で新しいバージョンを確認し、「アップデートする」でダウンロード・確認（SHA-256）・インストール・再起動まで自動で行う。
- PawnIO ドライバーの同梱と自動インストール。
- Windows 11 の標準に合わせたダーク / ライトテーマ（読みやすい不透明な背景、Windows のアクセント カラーに追従）。
